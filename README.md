# Dynamic Data Table Manager

A dynamic data table built with Next.js, Redux Toolkit, and Material-UI.

## Features

- Dynamic Data Table with CRUD operations
- Column Management (Show/Hide, Add new)
- CSV Import/Export
-  Theme Toggle (Light/Dark mode)
-  Search, Sort, Pagination
-  Inline Editing

## Tech Stack

- Next.js 14
- Redux Toolkit
- Material-UI (MUI)
- TypeScript
